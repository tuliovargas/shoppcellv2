# Change Protocol

## FEATURE

BRD/PRD impact → SDD impact → Spec → Plan → Implementation → Tests → Documentation

## BUGFIX

Reproduce → Root Cause → Impact → Fix → Regression Test → Verification

## REFACTOR

Current Behavior → Technical Problem → Impact → Plan → Refactor → Regression Tests

## CHANGE

Current Behavior → Requirement → Impact → Spec → Plan → Implementation → Tests

## HOTFIX

Root Cause → Minimal Safe Fix → Verification → Regression Test → Permanent Fix Assessment

## REMOVAL

Consumers → Dependencies → Migration/Compatibility → Removal → Tests → Documentation
