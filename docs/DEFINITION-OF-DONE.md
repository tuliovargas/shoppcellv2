# Definition of Done

A task is considered complete when applicable items are checked.

## Requirements
- [ ] Requirement understood
- [ ] Acceptance criteria defined
- [ ] Relevant Spec updated

## Architecture
- [ ] Existing architecture respected
- [ ] Impact analyzed
- [ ] Architectural decision documented if needed

## Implementation
- [ ] Code implemented
- [ ] Existing functionality reused where appropriate
- [ ] No unnecessary duplication
- [ ] Validation implemented
- [ ] Authorization verified
- [ ] Error handling considered

## Database
- [ ] Schema changes reviewed
- [ ] Migration created when necessary
- [ ] Data integrity considered
- [ ] Indexes considered

## Quality
- [ ] Tests added/updated
- [ ] Relevant tests/checks executed
- [ ] Regression risk reviewed

## Security
- [ ] Authentication considered
- [ ] Authorization considered
- [ ] Sensitive data protected
- [ ] Secrets not exposed

## Documentation
- [ ] API documentation updated if necessary
- [ ] Architecture documentation updated if necessary
- [ ] Feature Spec synchronized

## Final
- [ ] No unrelated changes
- [ ] Known limitations reported
- [ ] Final verification reported honestly
